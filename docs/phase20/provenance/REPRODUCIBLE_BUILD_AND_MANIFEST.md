## Trust and security limitations

- Source hash/code pin/nonce stored by an attacker controlling every
  artifact do NOT independently authenticate a producer. Revalidating
  source bytes is valuable for reproducibility, not for authorization.
- The public scalar probe can be called from untrusted JS but is
  stateless PURE toy math; it does NOT issue, mint or consume W03
  Ticket, ServiceId permission, private quota, clock ledger or guest
  CpuContext pointer.
- The real P19 W03 scheduler private Ticket+clock clock can use a
  candidate computed by a trusted native test harness; it does not
  yet execute this leaf INTERNALLY or debit a P20 service quota.
  That integration requires Peach's exact reviewed source snapshot.
- Toad V2 computes a public CandidateV2 with proposedCost=1, NOT a
  granted budget/authorization. A caller can forge EVERY ViewV2
  field including origin, claimedBudget and epoch.
- Actual Nintendo source identity/profile mismatch remains; trusted
  independently signed C# producer unavailable; original HLE/IOS/GX/
  VI/IRQ absent; playable Wii game never claimed.
