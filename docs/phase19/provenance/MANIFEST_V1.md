# Phase19 artifact lineage manifest v1: machine-readable contract for Peach

**FORMAT: nsmb-invented-artifact-lineage, version integer 1.**
Generated by scripts/phase19/luigi/lineage.py after real compilation,
NOT signed by a trusted external authority. Not a Wii release manifest.
Peach's browser/W03 artifact has an INDEPENDENT schema and must not
pretend to originate from Luigi's invented PowerPC code.

Root JSON fields, all mandatory:
- format, version: above; unknown fields refused.
- runNonce: 32 lowercase hex chars externally supplied before child
  execution. Must equal a caller-provided expected_nonce on verification.
  This cannot defend against replay if both nonce and root are attacker
  controlled; use a separate observer with an unpredictable challenge.
- sourceRunId: deterministic toy model digest of fabricated input bytes,
  NOT an attestation signature.
- git: head and tree, 40 lowercase Git hex chars; source checkout identity
  is recorded but changing the manifest alone cannot prove real lineage.
- upstreamCsPin: public C# source gitlink
  20f0158dd1d96bd94f821adf80ee361e4fbd414e; source-only, never built.
- producerCodePins: SHA256 of seven real Python/JS tool source files
  (Phase18 toy parent producer/witness, Phase19 toy model, child emitter,
  replay verifier, lineage verifier and Node Wasm verifier). The verifier
  compares their physical current bytes. No runtime producer signature.
- files: object of EXACT 10 allowed relative paths. Every entry has
  sha256 full lowercase 64 hex and bytes exact integer; all real file
  contents, existence, size, ancestor symlinks and unexpected additional
  files are validated, not just manifest assertions:
    inputs/source.dol
    inputs/inputs.map
    inputs/config.json
    generated/invented_guest.cpp
    native/toy_native
    wasm/invented_guest.wasm
    witness.json
    cpp_origin.json
    node.json
    pins.json
  Manifest itself is separate manifest.json; caller supplies its full
  SHA256 out of band. Files with extra names, symlinks or path traversal
  are rejected. Witness report must be exactly Phase18 34-event toy STOP.
- compiler: imageDigest exact local Docker image SHA, toolchain string
  cached Emscripten 6.0.13, network none, sourceMount read-only,
  outputMount temporary writable, nativeFlags and wasmFlags (standalone
  Wasm no-entry, exact three toy exports). This is a RECORD of what
  runner invoked, NOT independent verified provenance of em++.
- abi: physical Wasm imports empty, exact actual export list and
  caseCount 24, from Node Wasm.Module and dynamic test report. No raw
  CpuContext* exposed, no native HLE registered.
- provenance: exact booleans toyReplay=true, producerAttested=false,
  authenticReleaseEligible=false, externalTrustedWitnessPresent=false.
  Attempts to flip these via self-rehashing are rejected.

## Verification sequence (fail-closed)
1. Compare manifest bytes to independently provided expected SHA, plus
   expected nonce and expected WASM SHA from a separate reviewer.
2. Strict decoded JSON with duplicate key / Unicode-escaped duplicate
   key rejection, exact typed fields, no unknown keys.
3. Compare all 10 physical SHA/size and file inventory, including
   symlink parent directories and separate pins.json.
4. Re-create invented source from OWN hard-coded fixture; reject
   mutated private/unrecognized source EVEN IF re-pinned in all JSON.
5. Independently re-decode PPC, regenerate C++ and compare exact bytes.
   Compare C++ emission record raw bytes including REQUIRED trailing LF,
   no automatic fixing of truncation (a real RED defect was found).
6. Validate Phase18 separate process witness STOP and source inputs;
   check local producer-code SHA pins.
7. Run the physical native executable over 24 source-oracle vectors.
8. Instantiate and run the physical Wasm through Node with zero
   imports/expected exports/source-tag+24 vectors; compare the freshly
   produced Node report to byte-pinned node.json. It is forbidden to
   infer CPU output solely from static WebAssembly.validate.
9. Return status INVENTED_MULTIFILE_CHAIN_VERIFIED_STOP (CLI exit3).
   Any mismatch => CLI exit4; never an authentic release result.

## Red-green and dangerous blind spots
- RED: an incomplete C++ emission record without final newline was
  being normalized into valid JSON. GREEN: compare raw original event
  bytes without appending newline. Tests pin this regression.
- RED: merely inspecting symlink final leaf misses an ancestor symlink.
  GREEN: inspect EVERY relative path component and parent directories,
  reject external-file redirects.
- Prior generic subprocess.run(capture_output=true) did not bound
  hostile child output WHILE alive. GREEN: selectors+os.read(4096),
  500KB per stream, monotonic timeout, kill/reap, close pipes.
- A physical Wasm swapped from Mario's different build, even with
  self-repinned manifest, is denied against independent expected SHA.
  Native swapped with /bin/true and re-pinned is denied by physical
  native invocation, not just SHA.
- A fabricated, self-consistent source/emitter AND independently
  supplied pins from SAME attacker can still fool a static verifier.
  Mandatory source-genuine trust witness does NOT exist here.
- A second Docker compilation reproducibly yields same 777-byte Wasm.
  It proves build determinism under one image, not that Docker image,
  physical hardware or producer are trusted/authenticated.

## Separate external public Wasm link contract

scripts/phase19/luigi/external.py reads an independent Phase18 artifact
manifest format nsmb-phase18-synthetic-wasm-artifact-v1. Checks EXACT
external expected Git SHA and Wasm SHA, physical 12 public source files,
Wasm and MJS digests, actual WebAssembly imports and exports. Result is
PUBLIC_NEW_WASM_SOURCE_STATIC_LINK_STOP, with
guestCpuClockActuallyInvoked=false. Peach may submit a NEW artifact dir,
SHA and dynamic browser proof; Luigi will review actual source/HEAD
and run native Node/Chrome checks ONLY when those bytes exist.
Neither link means Mario's Wasm was emitted from Luigi's toy C++.
